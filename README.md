# Automatic Crusader Kings 3 DLC Unlocker Tool

**CK3Unlocker** is an all-in-one utility for unlocking and activating downloadable content (DLC) for **Crusader Kings III** on Steam.

Designed to keep things simple, CK3Unlocker automates DLC detection and configuration, making it easier to manage your game content without unnecessary manual setup.

## 🧰 Requirements

Before using CK3Unlocker, make sure you have:

- A legitimate Steam installation of **Crusader Kings III**.
- The relevant DLC available on your Steam account.
- Steam installed and running in the background.
- An active internet connection when online data retrieval is required.
- The required .NET Runtime for your version of CK3Unlocker.

## ⚡ Installation & Setup

### 1. Download CK3Unlocker

Download the latest release from the project's Releases page and extract the files into a folder of your choice.

### 2. Launch CK3Unlocker

Run the executable and follow any permission prompts displayed by Windows.

### 3. Select the Game Directory

Choose your Crusader Kings III installation folder.

The default Steam installation path is usually:

```text
Steam/steamapps/common/Crusader Kings III
```

### 4. Detect DLC

Allow CK3Unlocker to scan your installation and identify available DLC.

### 5. Configure DLC

Follow the application's instructions to configure and activate content available to your Steam account.

### 6. Launch the Game

Start Crusader Kings III through Steam and check the in-game DLC menu.

## 🔧 Troubleshooting

| Issue | Possible Solution |
|---|---|
| DLC not appearing in-game | Check your Steam DLC settings and verify that the content is installed. |
| Game crashes on launch | Verify the integrity of your game files through Steam. |
| Missing DLL errors | Make sure the required application dependencies are installed. |
| Game directory not detected | Manually select your Crusader Kings III installation folder. |
| DLC status not updating | Restart Steam and refresh the DLC detection. |
| Problems after a game update | Check for a newer CK3Unlocker release and verify your game files. |
